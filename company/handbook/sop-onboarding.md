# SOP — onboarding a new hire

## 1. Employee record (PeoplePort)

Create the record via "New hire". Required: full name, **personal email**, job title, department,
manager, start date and **employment type** (Full-time / Part-time / Contractor).
If any required detail was not provided, **ask the person who requested the onboarding** — do not guess.

## 2. Access — least privilege

- Look up the new hire's role in the **role access matrix**: shared drive `hr/role_access_matrix.xlsx`
  (sheet "Access matrix").
- Grant **exactly** the entitlements listed for the role (codes like `email`, `crm:sales-user`,
  `helpdesk:viewer`). Nothing more, even if asked informally.
- Some entitlements need IT Security approval (noted in the matrix); the system enforces this.
- After granting `email`, note the generated work email address from the employee page.

## 3. Equipment

Email **it-helpdesk@northwind.example** to request the equipment listed for the role on the
"Equipment" sheet of the matrix. Include the name, start date and work email.

## 4. Notify the manager

Email the hiring manager with: employee ID, start date, work email address and the access granted.
